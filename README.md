# Robot hero animation

A premium white-ceramic sci-fi robot, built procedurally in Three.js and animated to a fixed, looping 9-second script. Use it as an autoplaying website hero:

- **`media/robot-loop.mp4` / `media/robot-loop.webm`**: 1440×2160 (2:3), 30 fps, 9 s, seamless loop, no audio
- **`media/robot-loop-poster.jpg`**: first frame (identical to the last), for `poster=`
- **`index.html`**: example hero with an empty left column for the headline and CTAs
- **`robot.html`**: the same scene rendered live in WebGL (no video needed)

## Animation script

| Time | Action |
| --- | --- |
| 0–2 s | Starts in side profile, head bowed, as in the reference. The eyes lead, then the head turns deliberately to face the viewer. The lower vertebrae lead the turn and it ends with a ~3° mechanical overshoot that settles. |
| 2–4 s | Two precise mechanical blinks with a short pause between them. Titanium upper and lower shutters close fast and open more slowly. |
| 4–7 s | Holds eye contact. Small eye saccades left and right, a few degrees of head tilt, and micro neck adjustments. The neck pistons extend and compress to match. One natural blink. |
| 7–9 s | Calm return to the opening profile pose. Position and velocity match frame 0, so there's no jump at the loop point. |

Cables trail the head slightly (they're sampled from earlier poses), which gives secondary motion. Every movement is a pure function of time (`src/timeline.js`), so each frame is reproducible.

## Look

Ceramic armour with procedural panel seams, service markings and clearcoat; glossy black visor; woven carbon-fibre neck; brushed (anisotropic) titanium; ribbed cables. Lighting is a soft studio setup: a large softbox environment, a key light with soft shadows, plus rim and fill lights. GTAO contact shadows and a bloom pass that only catches the red LEDs.

The background is a single flat grey, **#dcdcdc**. It's calibrated through tone mapping so the rendered pixels match exactly. The page background in `index.html` uses the same value, so the video edge doesn't show.

## Run / re-render

```bash
npm install            # three + playwright (uses the preinstalled Chromium)
npm run vendor         # copies the needed three.js modules into vendor/ (already committed)
npm run serve          # http://localhost:8080/ (hero) and /robot.html (live 3D)
npm run render         # re-renders media/ (1440x2160, 30 fps); see flags in scripts/render.mjs
```

`robot.html?capture&w=1440&h=2160` exposes `window.__renderFrame(t)` for deterministic capture. `&quality=low` turns off GTAO and MSAA for slow machines.

## Tuning

- Camera, framing and lights: `src/main.js`
- Timing of the turn, blinks, saccades and tilt: `src/timeline.js`
- Geometry: `src/robot.js` (shells are generated by `src/shell.js`)
- Materials and textures: `src/materials.js`, `src/textures.js`
